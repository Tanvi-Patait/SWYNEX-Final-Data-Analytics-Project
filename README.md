# Iris Data Analytics — Final Project

## 1. Problem Statement
The objective of this project is to analyze the Iris flower dataset, clean the data, perform exploratory data analysis, and build an interactive Power BI dashboard to understand differences between Iris species.

## 2. Dataset Information
- **Dataset:** Iris Flower Dataset
- **Source:** kaggle 
- **Total Records:** 150
- **Total Columns:** 5
- **Features:** Sepal Length, Sepal Width, Petal Length, Petal Width, Species
- **Species:** Setosa, Versicolor, Virginica

## 3. Data Cleaning Process
The dataset was checked for missing values, duplicate records, incorrect data types, and inconsistent values. Cleaning operations were performed where necessary to prepare the data for analysis.

## 4. Exploratory Data Analysis
Python was used to explore the dataset, calculate descriptive statistics, compare flower measurements across species, and investigate relationships between features.

## 5. Power BI Dashboard
An interactive Power BI dashboard was developed to present flower measurements and species comparisons through KPI cards, charts, and slicers.

## 6. Key Insights
- Setosa generally has smaller petals than the other two species.
- Petal measurements help distinguish the three Iris species.
- Petal length and petal width show a strong positive relationship in the standard dataset.
- Comparing measurements by species reveals patterns that overall averages may hide.
